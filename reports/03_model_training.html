03 — Baseline model training¶

Predicts whether a booking will be cancelled by the customer (1) or completed (0). Uses the feature set and preprocessing pipeline from src/preproc.py (notebook 02).

Baseline technique: logistic regression. A random forest is trained alongside it as a second reference point, as planned in the README. Figures are written to reports/figures/ for the midterm report.

Models¶

Each model is wrapped in a pipeline with the shared preprocessor so the encoder is fit on training data only.

In [8]:
models = {
    "Majority class": DummyClassifier(strategy="most_frequent"),
    "Logistic regression": LogisticRegression(max_iter=2000),
    "Logistic regression (balanced)": LogisticRegression(max_iter=2000, class_weight="balanced"),
    "Random forest": RandomForestClassifier(n_estimators=200, min_samples_leaf=5,
                                            n_jobs=-1, random_state=RANDOM_STATE),
    "Random forest (balanced)": RandomForestClassifier(n_estimators=200, min_samples_leaf=5,
                                            class_weight="balanced", n_jobs=-1, random_state=RANDOM_STATE),
}

fitted, rows = {}, []
for name, clf in models.items():
    pipe = Pipeline([("prep", create_preprocessor()), ("clf", clf)])
    pipe.fit(X_train, y_train)
    pred = pipe.predict(X_test)
    proba = pipe.predict_proba(X_test)[:, 1]
    fitted[name] = pipe
    rows.append({
        "Model": name,
        "Accuracy": accuracy_score(y_test, pred),
        "Precision": precision_score(y_test, pred, zero_division=0),
        "Recall": recall_score(y_test, pred, zero_division=0),
        "F1": f1_score(y_test, pred, zero_division=0),
        "ROC-AUC": roc_auc_score(y_test, proba),
        "PR-AUC": average_precision_score(y_test, proba),
    })
    print("done:", name)

results = pd.DataFrame(rows).set_index("Model")
results.round(3)

Pilot for the proposed extension: driver time-to-arrive (Avg VTAT)¶

Every baseline above sits at chance. The booking-time features (where, when, which vehicle) carry almost no information about whether the customer will cancel.

One column was left out of the baseline on purpose: Avg VTAT, the driver's expected time to reach the pickup. It is missing only for No Driver Found bookings, so it is known at the moment a driver is matched, which is exactly when a driver decides whether to head toward the customer. The cell below checks whether it separates the two classes. This is a pilot only; the full extension (chronological split, tuning, calibration) is future work.

# Same logistic regression, same split, with Avg VTAT added as a numeric feature.
from sklearn.model_selection import cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder

X2 = X.copy(); X2["Avg VTAT"] = vt.values
X2_train, X2_test = X2.loc[X_train.index], X2.loc[X_test.index]

prep2 = ColumnTransformer([
    ("numeric", Pipeline([("imputer", SimpleImputer(strategy="median")), ("scale", StandardScaler())]),
                ["Hour", "DayOfWeek", "Month", "Avg VTAT"]),
    ("categorical", Pipeline([("imputer", SimpleImputer(strategy="most_frequent")),
                              ("encoder", OneHotEncoder(handle_unknown="ignore"))]),
                ["Vehicle Type", "Pickup Location", "Drop Location"]),
])
pilot = {
    "LR + VTAT": Pipeline([("prep", prep2), ("clf", LogisticRegression(max_iter=3000))]),
    "LR + VTAT (balanced)": Pipeline([("prep", prep2), ("clf", LogisticRegression(max_iter=3000, class_weight="balanced"))]),
}
prows = []
for name, pipe in pilot.items():
    pipe.fit(X2_train, y_train)
    pred = pipe.predict(X2_test); proba = pipe.predict_proba(X2_test)[:, 1]
    prows.append({"Model": name,
                  "Accuracy": accuracy_score(y_test, pred), "Precision": precision_score(y_test, pred, zero_division=0),
                  "Recall": recall_score(y_test, pred, zero_division=0), "F1": f1_score(y_test, pred, zero_division=0),
                  "ROC-AUC": roc_auc_score(y_test, proba), "PR-AUC": average_precision_score(y_test, proba)})
pilot_results = pd.DataFrame(prows).set_index("Model")
combined = pd.concat([results, pilot_results])
combined.round(3).to_csv("../reports/baseline_results.csv")
print(combined.round(3).to_string())

cv = cross_val_score(pilot["LR + VTAT"], X2, y, cv=5, scoring="roc_auc")
print("\n5-fold ROC-AUC, LR + VTAT: mean %.3f  (folds: %s)" % (cv.mean(), np.round(cv, 3)))
